# Quebec Minerals — карта минералов Квебека

Веб-приложение на **TypeScript + Vite + Leaflet**. Работает на Linux (и macOS/Windows): нужен только Node.js ≥ 20 и браузер.

## Запуск

```bash
./start.sh            # установит зависимости, соберёт и откроет http://localhost:4173
# или для разработки:
npm install
npm run dev           # http://localhost:5173
npm run fetch-data    # обновить выгрузку SIGÉOM в public/data/ (≈10 с)
```

## Что на карте

| Слой | Источник | Что даёт |
|---|---|---|
| Тепловая карта находок | SIGÉOM + OSM | Где плотнее всего проявления: рудники весят больше, чем простые проявления |
| Перспективные зоны | SIGÉOM (MRNF), WMS | Официальные зоны, которые министерство считает перспективными, с описанием |
| Металлы (8 622) / неметаллы (1 445) | SIGÉOM, WFS | Золото, медь, РЗЭ, литий… графит, слюда, гранат, апатит, лабрадорит, амазонит; фильтр по веществу |
| Выдающиеся геосайты, рудники | SIGÉOM | Геонаследие и действующие предприятия |
| Известные места ★ | Mindat и литература | Мон-Сент-Илер, Тетфорд, Джеффри, Ока, агаты Гаспези, Банкрофт, Херкимер… |
| Выходы пород, обрывы, осыпи/оползни, галечные пляжи, карьеры и отвалы | OpenStreetMap (Overpass) | Подгружаются при масштабе ≥ 11 |
| Геология, разломы, обнажения, гравий | SIGÉOM WMS, Macrostrat | Растровые слои; клик по карте показывает породу и зону в этой точке |

Поиск города идёт через Nominatim (OSM).

## Устройство

- `src/main.ts`: карта, слои, поиск, панель информации
- `src/osm.ts`: запросы Overpass с запасными зеркалами и кэшем
- `src/sigeom.ts`: WMS и GetFeatureInfo SIGÉOM
- `src/data/localities.ts`: подборка известных мест (координаты приблизительные)
- `scripts/fetch-data.ts`: выгрузка WFS SIGÉOM в `public/data/`
- `vite.config.ts`: прокси `/sigeom`, потому что сервер SIGÉOM отклоняет запросы с заголовком `Origin`. Поэтому приложение запускается через `vite`/`vite preview`, а не как статические файлы.
